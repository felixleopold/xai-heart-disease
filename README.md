# Heart Disease XAI — Final Assignment

Comparing SHAP and Partial Dependence Plots on a heart disease prediction model.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run

Open `code/assignment.ipynb` and run all cells.

## Files

- `code/assignment.ipynb` — notebook with all code and plots
- `code/data/heart.csv` — dataset
- `report/final-report.tex` — LaTeX source for the report
- `report/final-report.pdf` — compiled report
